Respuestas

Hashear contraseñas

Si la base de datos es comprometida, el atacante no obtiene las contraseñas reales sino valores irreversibles. bcrypt aplica un salt aleatorio y es computacionalmente costoso, dificultando ataques de fuerza bruta. Nunca se guardan contraseñas en texto plano.

Ventajas de SQLite en este proyecto

No requiere instalar un servidor de base de datos separado. El archivo .db se crea automáticamente. Es suficiente para proyectos de desarrollo. Viene incluido en Python sin dependencias extra. Toda la base de datos es un solo archivo portable.
